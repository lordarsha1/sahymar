# سهم‌یار V12

نسخهٔ سادهٔ ورود و ثبت‌نام: در مسیر `/api/auth`، ایمیل موجود با بررسی رمز عبور وارد می‌شود و برای ایمیل جدید حساب ساخته می‌شود. رمزها به‌صورت هش‌شده ذخیره می‌شوند.

## اجرا

Node.js 18 یا جدیدتر لازم است.

```sh
npm install
npm start
```

سپس `http://localhost:3000` را باز کنید. تنظیمات اختیاری در `.env.example` قرار دارد؛ برای استقرار، `SESSION_SECRET` را با مقدار تصادفی و امن جایگزین کنید.
